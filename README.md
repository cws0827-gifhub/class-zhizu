## 怎麼修改

整個網站就是一個 `index.html`，沒有任何相依套件，直接編輯即可。

- **改行事曆**：找到檔案下方 `var EVENTS = [` 那一段，每筆是一行。
  `s` 開始日、`e` 結束日（單日可省略）、`t` 標題、`n` 備註、`g` 分類標籤
  （分類可用：假期／評量／健康／報名／活動／重要）。
- **改文字**：直接搜尋該段文字修改。
- **改顏色**：檔案最上方 `:root{ ... }` 的色彩變數。

存檔後 commit、push，GitHub Pages 約一分鐘後自動更新。
